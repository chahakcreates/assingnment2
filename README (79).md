Each question folder contains:
- `Submission.docx` — formatted submission with topic, question, platform, problem link, C solution, and screenshot.
- `Solution.c` — C source code.
- `Submission_Screenshot.png` — submitted screenshot.

Screenshots are filed in the order of the Set 2 Part A question bank. Part B is not included in this package.
